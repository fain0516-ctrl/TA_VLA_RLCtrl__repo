# 03. 환경 및 Sim-to-Real 세팅 정리 (2023~2026 다지 손 RL 연구)

- 작성: 2026-09-29 / 계획 3단계
- 대상 로봇: 5지 평면 굴곡 손 (외전 없음). 4지 = MCP STS3215 직접 구동 + PIP/DIP 텐던(DS3225 PWM, 복귀 스프링 대항). 엄지 = STS3215 x2 직접 구동. 센서: 촉각, 외부 비전/VLA, 모터 내장 Load·온도·자기식 엔코더.
- 비교 기준: 팀 문서 `AI_Priority_Rules/` (V6 SAC-HER, V1 MJX PPO, 10·11번 규격서).
- 표기: **[검증]** = 논문 본문/코드에서 수치 확인. **[추정]** = 데이터시트 또는 일반 지식 기반, 팀이 실측으로 확인해야 함.

## 3. 액추에이터 모델링

### 3.1 STS3215 (MCP, 엄지) — 위치제어 서보

| 방법 | 출처 | 내용 | 결과 |
|---|---|---|---|
| 위치 액추에이터 5파라미터 식별 **[검증]** | P5 | 자유 파라미터: kp, 최대 토크, 감쇠, armature, 마찰. 알려진 부하를 단 모터에 여러 주파수 사인 지령 → 시뮬 궤적과 오차 최소화 | 식별값 예: kp 21.1, 최대토크 4.1 Nm, 감쇠 1.084, 마찰 0.03 (OP3 서보 기준, STS3215에 그대로 쓰지 말 것) |
| 확장 마찰 모델 BAM **[검증]** | P8 | Coulomb-Viscous 대신 Stribeck, 하중 의존, 방향 비대칭, 속도 2차항 포함. **STS3215 사전 식별 모델 제공**, MuJoCo CPU/Warp API | 모델 정밀도가 정책 전이에 직접 영향 (논문 주장) |
| armature = 기어비² × 로터 관성 **[검증]** | P7, P13 | LEAP: 기어비 288.35, 로터 1.7e-8 → 1.41e-3 kg·m². 마찰손실 = 최대 토크의 10%. Aero: 기어비 205 → 1.56e-3 | 저가 서보는 반사 관성이 링크 관성보다 큼 → armature 누락 시 과도 응답 불일치 |
| 전류→토크 보정 + 토크-속도 곡선 **[검증]** | P10 | 토크센서 없이 모터 전류로 관절 토크 추정. 스톨 토크, 속도 상수, 마찰/리플, 백래시 랜덤화 | 힘 기반 파지 제로샷 전이 |
| delta action 보정 | P15 | 실기 궤적과 시뮬 차이를 행동 보정 네트워크로 학습해 시뮬에 삽입 후 재학습 | 식별로 못 잡는 서보 응답 잔차 보정용 (2차 수단) |
| autotune (real-to-sim) **[검증]** | P6 | 제조사 모델 기반 K개 파라미터 조합 랜덤 샘플 → 실기와 병렬 시뮬에서 동일 지령 → MSE 최소 선택. 4분 이내 | MSE 최저 8/10, 중간 3/10, 최고 0/10 파지 성공 |

**팀 적용**
1. MCP STS3215: BAM의 STS3215 모델을 초기값으로 사용 → 팀 손가락 부하(링크+텐던 장력)로 P5 방식 사인 스윕 재식별.
2. 슬루 제한 6.0 rad/s: 데이터시트 무부하 속도 **[추정]** 7.4 V 약 0.22 s/60° (≈4.7 rad/s), 12 V 약 0.18 s/60° (≈5.8 rad/s). 전압·부하에 따라 달라지므로 실측 최대 속도로 교체하고 ±15% DR.
3. **Load 레지스터 해석 주의 [추정]**: STS 계열 Load는 PWM 듀티 비율 기반 값이라 토크가 아니라 인가 전압에 비례. 속도(역기전력)·마찰이 섞여 있음. P10처럼 (Load, 속도, 온도) → 토크 매핑을 정지 부하 시험으로 보정해야 외력 추정(DOB)에 사용 가능. 펌웨어/모델별 전류 레지스터 유무 확인 필요.
4. 온도: 장시간 파지 시 권선 저항 증가로 토크 상수 저하 **[추정]**. 훈련 DR에 최대 토크 ×0.85~1.0 포함, 실기에서 온도 임계 시 파지력 목표 하향.

### 3.2 PIP/DIP 텐던 (DS3225 PWM 서보 + 복귀 스프링)

| 방법 | 출처 | 내용 | 결과/실패 |
|---|---|---|---|
| 해석적 관절→텐던 길이 맵 l = f(q) **[검증]** | P4 | CAD 기반 롤링 관절·텐던 경로 모델, 가상 힌지 2개를 tendon/fixed로 연동 | 접촉 시 **텐던 신장**으로 관절 추정 오차 → 관측값에 0.5 곱하는 임시방편. 큐브 재배향은 실기 실패 (시스템 식별 부족) |
| 유효 권선 반경 선형 맵 **[검증]** | P13 | 손가락: MCP 12.49, PIP 7.32, DIP 9.00 mm/rad. MuJoCo 공간 텐던 20개, 라우팅 실린더 반경 1.7~4.5 mm, 스프링 강성 352 / 4000 N/m, 텐던 위치 액추에이터 kp=1e4 | 전달 맵 정확도가 제로샷 전이 결정 요인 (6.3절 ablation) |
| 선형 커플링 q_u = k·q_a + b, k·b를 autotune **[검증]** | P6 | 언더액추에이티드 관절을 선형 함수로 근사 | autotune 대상에 포함해 전이 성공 |
| 학습형 텐던 힘 모델 **[검증]** | P11 | 입력: 1.5 s(20 Hz×30) 목표위치·측정위치·속도 이력 → 텐던 힘. Transformer 최고, RNN 발산. 36분 데이터(80 Hz), 막힘(blocking) 시나리오 포함 | 힘 RMSE 0.61 N(최대힘의 2.9%). 이상적 힘원 대비 궤적 오차 14.58→8.61 mm(41%↓), RL 추종 24→12 mm(50%↓) |
| 자동 캘리브레이션(스톨 감지) **[검증]** | P9 | 굴곡/신전 한계까지 구동 → 스톨 위치 기록 → 선형 전달비 산출 | 주기적 재장력 조정 필요 |

**팀 적용 (가장 큰 갭)**
1. 현재 `tendon_ctrl = rl_action × 1.5` 고정 비율 → **비권장.** P13 방식으로 CAD에서 MCP/PIP/DIP 유효 권선 반경을 뽑아 `ΔL = r_mcp·Δq_mcp + r_pip·Δq_pip + r_dip·Δq_dip` 맵 사용. ADR 005의 `ΔL = r_mcp Δq_mcp` 피드포워드와 동일 모델을 시뮬·실기에 공유.
2. Capstan 마찰 η = e^(−μθ) ≈ 0.5~0.7 (10번 문서): MuJoCo 텐던 `frictionloss`는 상수라 재현 불가 → 액추에이터 힘에 η를 곱하는 전처리로 구현하고 **η를 U(0.45, 0.8) DR [추정: 문서 값 ±]**, 방향(당김/풀림) 비대칭 포함.
3. **DS3225는 위치·부하 피드백이 없음 [추정: 일반 PWM 서보 사양].** 텐던 측 상태는 관측 불가 → 정책 관측에서 텐던 위치를 "명령값"으로만 제공하고, 실제 PIP 각도는 시뮬 critic(특권 정보)에만 제공. PIP/DIP 관절 센서가 없다면 P4의 관절 추정 실패가 그대로 재현될 위험.
4. P11 교훈: 스프링 대항 텐던은 이상적 힘원 가정 시 **신전(펴기) 구간 오버슈트**가 주 오차. 팀의 해제 시퀀스 락(40KG/DS3225 선행 릴리즈)과 같은 구간이므로 이 구간 궤적을 우선 실측·식별.
5. 문서 불일치: 팀 문서(ADR 005, 10번)는 텐던 모터를 "40KG PWM"으로 기록, 사용자 설명은 DS3225(약 25 kg·cm급 **[추정]**). 토크 한계 DR 기준값을 정하기 전 확정 필요.
6. PCA9685 PWM 갱신 50 Hz → 텐던 지령 최소 20 ms 양자화. 시뮬에서 텐던 지령을 20 ms 제로오더홀드 + 서보 데드밴드 적용 **[추정]**.

## 7. 권장 / 비권장 요약

**권장**
- 시스템 식별 먼저, DR은 식별값 주변 ±10~30% (P5, P6, P7, P11).
- STS3215: BAM 사전 모델 → 팀 부하로 사인 스윕 재식별 (P5, P8).
- 텐던: CAD 권선 반경 맵 + 스프링 + η 곱 전처리, 스톨 기반 자동 캘리브레이션 (P9, P13). 여력 있으면 1.5 s 이력 Transformer 텐던 힘 모델 (P11).
- 정책 20~25 Hz, 행동 지연 0~1.5 step, 관측 지연 10~50 ms, 행동 저역통과 (P1, P5).
- 관측에 이전 행동, 위치 오차, 3~4 step 이력 (P2, P7).
- 촉각: 이진(보정 임계, 드롭 0.1) + 양자화 힘 (P3, P12).
- 시드 여러 개 실기 비교 (P1).

**비권장**
- 2018 OpenAI 광범위 DR 그대로 사용 (감쇠 ×0.2~20, 질량 ×0.25~4, dt 8배 변동).
- 텐던을 고정 비율(`×1.5`) 또는 이상적 힘원으로 모델링 (P4, P11).
- 정책 100 Hz 실기 배포 (P7).
- 센서 하한 근처(0.15~0.5 N) 연속 촉각값을 무보정 사용 (P3).
- Load 레지스터를 토크로 직접 사용 **[추정]**.

**실패값 (논문 보고)**
- autotune MSE 상위 → 0/10 (P6). 이상적 텐던 힘원 → 24 mm 오차 (P11 대비 12 mm). 연속 촉각 → 0.33 (이진 1.08) (P3). 관측 ×0.5 임시방편 필요 (P4).

## 8. 추가 연구·실측 필요 항목 (4단계 입력용)

## 9. 문헌 공백 (1번 스레드와 공통 결론)

- MCP 직결 서보 + PIP/DIP 텐던 **혼합 구동** 손을 한 정책으로 학습한 사례 없음. P13은 전 관절 텐던, LEAP(P7)은 전 관절 직결.
- DS3225처럼 **상태 피드백이 없는 액추에이터**의 sim-to-real 사례 없음. 텐던 측 상태는 STS3215 위치오차·촉각으로 간접 추정해야 함 (3.2절 3번).
- 두 공백 모두 팀이 직접 식별 실험으로 메워야 하는 항목이며 8절 1~4번이 그 실험.
