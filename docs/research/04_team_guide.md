## 0. 한 페이지 요약

**가장 먼저 바꿀 것 5가지 (코드 수정량 작음, 효과 큼)**

1. **"HER"를 끈다.** 현재는 실패 샘플(R ≤ -10)의 50%를 R=+1, done=False로 바꿉니다. 이는 목표 재라벨링이 아니라 실패에 보상을 주는 데이터 오염입니다. (02 §0-1)
2. **파손 -30 즉시 종료를 선형 과힘 패널티 `-β·max(0, F−F_th)` (β 0.05~0.2)로 바꾼다.** 팀 09번의 "닿고 도망치는" 현상이 이 벌점에서 나왔고, FORGE·CaT가 같은 문제를 이 방식으로 풉니다. (02 §2.2)
3. **파지 보상을 계단형(+10/+2)에서 목표 힘 가우시안 `exp(-(F−F_cmd)²/2σ²)`로 바꾸고, 목표 힘 F_cmd와 파손 한계 F_th를 Actor 관측에 넣는다.** (ByteDance 2025, FORGE)
4. **V1 MJX의 2018식 DR 범위를 줄인다.** 감쇠 ×0.2~20, 링크 질량 ×0.25~4, dt 8배 변동은 2023+ 관행(±10~30%)보다 한 자릿수 넓습니다. (03 §4.2)
5. **정책 주기를 100 Hz에서 20~25 Hz로 내리고 행동을 Δ(증분)로 바꾼다.** 텐던 PWM 갱신과 버스 지연 때문에 100 Hz 정책은 실기에서 그대로 돌지 않을 가능성이 큽니다. (03 §2, 02 §5)

**실기 전 반드시 측정할 것 3가지**: 텐던 모터 사양 확정(40KG vs DS3225), 촉각 센서의 0.15~0.5 N 구간 신뢰도, STS3215 Load 값과 실제 외력의 관계. (§4)

**문헌에 답이 없어서 팀이 직접 메워야 하는 것 2가지**: 직결 서보 + 피드백 없는 텐던 서보의 혼합 구동 손, 1 N 이하 미세 파지력 추종. (§6)

### P1. V7 훈련 세팅 (MJX PPO로 이전하면서)

- [ ] **P1-1 보상 재작성** (02 §2.4 초안 기반, 1지 버전)
  ```
  r =  w_F · c · exp(-(F − F_cmd)² / 2σ_F²)        # 접촉 시에만, σ_F ≈ 0.1~0.2 N [추론]
     + w_L · c · exp(-(L − L_cmd)² / 2σ_L²)        # STS3215 Load 추종 (보정 후, P2-3)
     + w_c · 1/(1 + α·d_tip)                        # 접근 단계
     − β   · max(0, F − F_th)                       # β 0.05~0.2 [논문 FORGE]
     − w_Δ · ‖a_t − a_{t−1}‖²                        # 규모는 P0-2 테스트로 결정
     + B_s · 1[k 스텝 연속 유지]  − P_drop · 1[낙하/미끄럼]
  ```
  - 권장: 항은 적게 [논문 Text2Touch, Eureka]. 진행 보상은 "최고 기록 갱신분만" 지급 [논문 DexPBT, DextrAH-G].
  - 비권장: 계단형 상수 보상, 큰 종료 벌점(-30~-50) 단독 사용, 온도 패널티를 첫 버전에 넣는 것(문헌 근거 없음, §6).
  - 실패값: 힘 패널티 제거 → 성공률 0.84→0.64 [FORGE]. LCP λ 0.01 → 수익 26.0→16.1 [LCP].
  - 참고: 힘 추종은 접촉력 + 토크(Load) 항을 **함께** 둬야 한쪽이 낮게 나오지 않습니다 [ByteDance Table 3].

- [ ] **P1-2 관측·행동 재정의**
  - Actor 관측(1지): q_mcp, 텐던 명령값(DS3225는 피드백 없음), 이전 행동, 위치오차(명령−측정), 이진 접촉 + 3~4구간 양자화 힘, slip, F_cmd, F_th, 위 항목의 3~4 스텝 이력.
  - Critic 추가(특권): 물체 반경·질량·마찰, 무노이즈 접촉력, 텐던 장력, 실제 PIP/DIP 각도.
  - 행동: [Δq_mcp, Δtendon] 2차원, 20~25 Hz, Δ 상한 = 실측 최대 속도 × 정책 주기. STS3215 6 rad/s 가정 시 0.24~0.3 rad/스텝 [추론].
  - 평활: EMA η 0.5~0.8 또는 행동 저역통과 u = 0.8·u_prev + 0.2·a [논문 AnyRotate, OP3].
  - 비권장: 텐던을 `a·1.5` 고정 비율로 묶는 것. 소형 물체에서 PIP/DIP 굽힘량을 따로 조절할 수 없습니다.

- [ ] **P1-3 안전층을 시뮬 루프 안에**
  - Slew 제한, 촉각 래치, 어드미턴스(K_d 5, D_d 1.5, M_d 0.02), 해제 시퀀스 락(텐던 선행 릴리즈)을 **훈련 환경 step 안에** 두고, 정책은 그 위에서 학습. 실기 노드와 같은 코드(또는 같은 수식)를 공유. [논문 DextrAH-G, 추론]
  - 역할 분담 권장: 정책 = "어디까지, 얼마나 세게(F_cmd 스케일)", 하위층 = "안전과 추종". 09번의 래치는 보상 수정 후에는 안전장치로 남기고 정책을 대체하지 않게 둡니다.

- [ ] **P1-4 알고리즘·스케일**
  - V1 MJX PPO(4096 env)를 주 경로로. 시작 HP: §1 표 "네트워크·HP" 행.
  - 총 1~3억 스텝부터. MuJoCo Playground LEAP은 2×RTX 4090에서 30분에 약 3억 스텝이므로, 4090 1장에서 수 시간 안에 결과가 나와야 정상 [논문, 추론].
  - SAC 경로(V6 계열)는 1지 비교 기준선과 실기 미세조정(HIL-SERL: 데모:온라인 50:50, 시연 20~30개 + 사람 개입)용으로 유지.
  - 여유가 되면 PBT(인구 8~32)로 보상 가중치·HP 탐색 [논문 DexPBT].

- [ ] **P1-5 커리큘럼**
  - 물체 반경: 2.6~3.4 cm에서 시작 → 성공률 기준으로 1.5 cm까지 확장(ADR식: 성공 20회 연속이면 확장, 5회면 축소) [논문 DeXtreme, 추론].
  - 초기 자세: 접근 직전 자세 여러 개에서 리셋. 단일 초기 자세는 학습 불안정 [논문 PenSpin].
  - F_th: 에피소드마다 랜덤화하고 관측에 넣음(예: 1.0~3.0 N) [추론, FORGE 5~10 N을 우리 스케일로].

### P2. 환경·Sim-to-Real (실기 배포 전)

- [ ] **P2-1 STS3215 식별**: BAM의 STS3215 사전 모델 → 팀 손가락 부하로 사인 스윕 재식별(kp, 최대토크, 감쇠, armature, 마찰, 최대속도). 방법은 OP3 5파라미터 식별 [논문 P5, P8]. 식별 후 autotune(파라미터 조합 병렬 시뮬, 실기 궤적 MSE 최소 선택): MSE 최저 8/10 vs 최고 0/10 성공 [논문 Lin 2025].
- [ ] **P2-2 텐던 모델**: CAD에서 MCP/PIP/DIP 유효 권선 반경 추출 → `ΔL = r_mcp·Δq_mcp + r_pip·Δq_pip + r_dip·Δq_dip`. 스프링 강성, η 전처리(0.45~0.8 DR, 당김/풀림 비대칭), 20 ms ZOH + 데드밴드. 이 맵을 ADR 005 피드포워드와 **같은 수식으로 공유** [논문 Aero Hand, 03 §3.2].
- [ ] **P2-3 Load → 힘 보정**: 손끝에 알려진 힘(추 또는 로드셀)을 가하고 (Load, 속도, 온도) → 외력 선형/저차 보정. 보정 전에는 Load를 토크로 쓰지 않음 [논문 ByteDance, 03 §3.1-3].
- [ ] **P2-4 DR 범위 재설정**: 03 §4.3 표를 초기값으로. 범위는 "식별값 정책을 파라미터별로 넓혀 성공률이 무너지는 경계"를 측정해 그 안에서 결정 [논문 DrEureka].
  - 비권장 값: 감쇠 ×0.2~20, 링크 질량 ×0.25~4, Kp ×0.5~2, dt 0.0125~0.1 s, 마찰 하한 0.1 [팀 V1 → 03 §4.2].
- [ ] **P2-5 지연 실측 → DR**: 명령 타임스탬프 → 엔코더 변화 시점 분포(UART 데이지체인, I2C PCA9685, ROS2). 실측 전 임시값: 행동 0~1.5 step, 관측 10~50 ms.
- [ ] **P2-6 촉각 표현**: 이진 접촉(센서별 보정 임계, 드롭 0.1) + 3~4구간 양자화 힘. 연속 원값은 스케일 DR ×0.7~1.3과 노이즈를 넣을 때만 [논문 Yin 2023: 이진 1.08 vs 연속 0.33, 03 §5.3].
- [ ] **P2-7 정지 압착 시험**: 같은 명령에서 sim/real 접촉력 비교 → solref(접촉 강성) 조정. 0.5 N 영역은 solref에 민감 [추론].
- [ ] **P2-8 실기 이전 절차**: 시드 3개 이상 실기 비교 [논문 DeXtreme: 시드별 실기 편차]. zero-shot이 안 되면 PenSpin 방식(시뮬 정책 개루프 재생 → 성공 궤적 50개 미만 수집 → 미세조정) 또는 HIL-SERL.

### P3. 확장 (1지 → 5지, 상위 연동)

- [ ] **P3-1 손가락 확장**: 4지는 구조가 같으므로 **손가락 공유 정책(파라미터 공유) + 손가락 ID 임베딩**으로 시작 [추론]. 4지 굽힘 분산 패널티로 동조 [논문 ByteDance]. 엄지 2축은 별도 헤드.
- [ ] **P3-2 VLA 인터페이스**: VLA는 "무엇을/어디를/F_cmd·F_th", RL은 "어떻게 쥘지" [논문 DexGraspVLA, 01 §6]. 인터페이스 변수는 P1-2 관측의 F_cmd, F_th와 물체 크기 추정치로 정의하면 훈련 관측과 바로 맞습니다.
- [ ] **P3-3 온도 대응**: 보상이 아니라 하위 규칙으로. 온도 임계 시 F_cmd 하향·토크 제한 [논문 LEAP: 과열은 전류 제한으로 해결]. 시뮬 DR에는 최대 토크 ×0.85~1.0만 반영.
- [ ] **P3-4 떨림 추가 억제가 필요할 때**: 보상 패널티를 키우지 말고 LCP(λ_gp 0.002) 또는 EMA 강화 [논문 LCP].
